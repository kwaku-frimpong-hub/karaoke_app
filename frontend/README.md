# frontend

React + TypeScript frontend for the Friday Karaoke application (Vite).

See the repository root `README.md` and `docs/RUNBOOK.md` for setup and commands.

## Local development

```bash
npm install
npm run dev
```

The dev server runs at http://localhost:5173 by default.

## Checks

```bash
npm run typecheck   # TypeScript
npm run lint        # oxlint
npm run build       # production build
```

## Status

M0 scaffold only — a placeholder screen. Participant queue UI and the host
dashboard arrive in later milestones (M8, M9).
